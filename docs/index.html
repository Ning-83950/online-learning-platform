  • 系统配置维护

Core Modules

核心功能模块

七大模块覆盖在线教育的完整教学流程

📚

课程管理

课程 CRUD、分类管理、封面图上传，支持富文本课程介绍，学生自主浏览与选课

📁

资料管理

教师上传课件视频/PDF 文档，学生在学习资料区按章节查看，支持多种文件格式

📝

作业系统

教师发布作业设定截止时间，学生在线提交（文件/文本），教师批改并打分

📊

考试系统

教师创建在线考试（选择题型），设定时间窗口，学生在线答题，系统自动判分出分

💬

讨论区

课程专属讨论版块，教师发起话题，学生参与讨论，促进师生互动

📒

学习笔记

学生在线记录学习笔记，关联到具体课程，支持随时查看与编辑

📈

数据看板

ECharts 可视化展示选课统计、考试通过率、学习活跃度等核心指标

👥

分组管理

教师创建学习小组、分配成员，支持小组协作学习模式
